Add **`content-inventory`**: escape accumulated design when redesigning a page. Given a scope (page, component, route, or flow), it traces the code and produces the complete list of what must be there — data, actions, inputs, states, navigation, feedback, plus the non-design invariants — with every design decision stripped: no widget names, positions, colors, sizes, or even on-screen order (items are alphabetised within groups). The result is one paste-able markdown block for a fresh design session, so the new design starts from first principles instead of inheriting the old UI's choices. Ships promoted in `engineering/` with a docs page and an `ask-matt` route pairing it with `/prototype`.
